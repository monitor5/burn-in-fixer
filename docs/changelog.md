# 변경 기록

## 2026-10-31 — 글씨 획 단위 보정: 희소 점등 측광

전면 gray 촬영은 카메라 영상을 긴 변 1600px로 줄여 디코드하므로 화면 1px에 카메라 약 0.5px만 돌아가고, 서브픽셀 모아레와 정합 오차 때문에 맵을 스무딩할 수밖에 없었다. 그래서 2px 획 글씨·버튼 테두리 번인은 보정 후에도 대부분 남았다(`research/stroke-level/`).

- **Target**: 희소 점등 패턴 `sparse{밝기}_b{블록}_p{피치}_x{위상}_y{위상}` 추가. 블록×블록 픽셀만 피치 간격으로 켜며, 안티에일리어싱 없이 픽셀 단위로 그린다.
- **Scanner `SparseSpotPhotometry`**: 메인 카메라 풀해상도 프레임(black 차감)에서 켜진 블록마다 무게중심으로 국소 정합하고, 무게중심에 맞춘 소수 경계 창으로 광량을 적분한다. 모아레와 렌즈 왜곡·호모그래피 오차가 블록 단위로 흡수된다. 위상 패턴마다 전면 맵과 비교해 피치 단위 배정 오류를 바로잡는다. 카메라 해상도에 맞춰 1px 블록(피치 3~6) 또는 2px 블록을 고르며, 화면 1px당 카메라 0.4px 미만이면 건너뛴다.
- **고주파 층**: 희소 맵에서 전면 경로의 스무딩 커널과 상보적인 고주파 비율만 가져와 스무딩 없이 화면 픽셀 단위 감쇠 층(`CorrectionMap.detail`)으로 만든다. 저주파는 기존 반복 루프가 그대로 맡는다. 반복 재측정값은 고주파 층의 평균 감쇠로 나눠, 저주파 루프가 이를 상쇄하지 않게 한다. 노이즈 수준의 편차는 Wiener 수축과 노이즈 분위수 보정으로 맵에 새기지 않는다. 고주파 층 단독 감쇠 상한은 6%이고, 최종 감쇠는 기존 상한 10%로 clamp한다.
- 리포트에 `strokeDetail`(블록·피치·패턴 수·카메라 배율·측정 비율·재정렬 위상 수·평균/최대 감쇠)을 기록한다.
- 측정 시간이 늘어난다. 1px 블록·피치 4 기준 black 8장과 16패턴 × 8장을 더 찍으며, 약 1분 추가된다.
- 합성 시험(`SparseSpotPhotometryTest`): 원근·배럴 왜곡, 1.2px 및 반 피치 가까운 정합 오차, 서브픽셀 발광 구조, 샷 노이즈 조건에서 2px 획·3px 링의 −3% 번인을 ±0.4~0.5%로 복원했다. 고주파 층 적용 후 획 대비는 80% 이상 줄었다. 노이즈만 있는 화면의 평균 감쇠는 0.5% 미만이다.
- 한계: 점만 켠 화면은 전면 점등과 OLED 구동 조건이 다를 수 있어 고주파만 사용한다. 디스플레이 해상도 축소 모드(예: QHD 패널을 FHD로 렌더링)에서는 블록이 번져 픽셀 단위가 아니게 된다. 실기기 검증은 하지 않았다.

## 2026-10-31 — 좁은 띠 번인의 거짓 합격 수정

알고리즘을 옮긴 합성 시뮬레이션에서 세로 폰 화면의 상태바·내비바 번인(면적 약 9%)이 "합격"으로 보고되면서도 실제 패널은 거의 개선되지 않는 세 경로를 확인하고 수정.

- **flat-field**: 반지름 bin 평균은 세로로 긴 화면의 바깥 bin이 상·하단 띠로만 채워져 띠 번인을 65~80% 비네팅으로 흡수했다. 블록 평균(긴 변 60등분)에 Tukey IRLS로 `c0 + c1·ρ² + c2·ρ⁴`를 맞추고 처음 3회는 ρ²만 쓰도록 교체. 합성 시험에서 띠·원형 국소 번인 흡수율 약 0%, 깨끗한 화면의 비네팅 제거 유지. 화면 전체에 걸친 매끄러운 방사형 패널 열화는 여전히 단일 촬영으로 비네팅과 구분할 수 없음(외부 flat-field 필요).
- **보정 목표**: 셀 단위 p10은 번인 면적이 10% 미만이면 정상 밝기에 걸려 보정이 거의 없었다. `Analyzer.correctionTarget`(블록 평균 하위 1%, 하한 `median·(1-maxAtt)`)으로 교체하고 gray70·gray25·RGB30 목표에 공통 적용.
- **합격 지표**: P95는 면적 5% 미만 결함을 정의상 무시하고 RMS는 면적에 희석된다. 블록 평균 최대 편차 `Analyzer.blockMaxDev`를 추가하고 합격 조건에 `≤ 2%`를 더함. 리포트에 `blockMaxDevBefore/After`, `lowLightBlockMaxDevBefore/After`, `passBlockMaxThreshold`, `blockSizePx` 기록.
- 회귀 테스트 `FalsePassRegressionTest`: 띠 번인 보존, 비네팅 제거, 목표 하한, 셀 지표 대비 블록 지표, 실제 패널 기준 보정 효과.
- 임계값 2%와 블록 크기는 내부 실험값이며 지각 한계나 공인 기준이 아님. 실기기 검증은 수행하지 않음.

## 2026-09-07 — main 병합

- main의 방사형 플랫필드 outlier 억제, 전체 화면 샘플링, 가장자리 감광 진단 및 테스트를 보존하여 병합.
- 리포트 함수 분리와 main 변경을 통합하면서 `edgeFalloff`를 명시적 인자로 전달하도록 연결.
- main에 추가되어 있던 IDE 설정도 Git 추적에서 제외하고 로컬 파일은 보존.
- 병합 결과에서 Scanner `:app:testDebugUnitTest :app:assembleDebug` 성공: 테스트 37개 통과, 실패·오류·건너뜀 0개. Target은 이전 검증 이후 코드 변경 없음(4개 통과).
