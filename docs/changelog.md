# 변경 기록

## 2026-09-07 — 연구 문서 및 저장소 정리

- README를 연구 목적·현재 범위·빠른 시작·문서 탐색 중심으로 재구성.
- 설치, 구조/프로토콜, 검증 한계, 로드맵, 연구·권리 안내, 기여 안내 분리.
- 초기 요구서와 과거 변경 기록은 [보관 디렉터리](archive/)로 이동.
- 비상업적 연구·교육 전용 자체 라이선스 및 제조사 비제휴 고지 추가.
- 외부 SDK·모델 조건을 별도 안내하고 프로젝트 라이선스와 구분.
- Scanner API 26, gray25, 감쇠 파라미터 0.10, 반복 상한 24 등 실제 코드에 맞게 문서 수정.
- 빌드 산출물, Gradle 캐시, IDE 설정, 로컬 SDK 경로를 Git 추적에서 제외. 로컬 파일은 보존하며 기존 커밋 이력은 재작성하지 않음.
- 작업 시작 시 존재하던 Scanner 코드·테스트·의존성 변경과 `VisionTrustGate`를 현재 실험 상태로 함께 기록. 이번 문서 작업에서 알고리즘을 새로 수정하지 않음.

### 검증

- Gradle 8.13과 Android Studio 번들 JDK에서 두 프로젝트의 `:app:testDebugUnitTest :app:assembleDebug` 실행 성공.
- Scanner 단위 테스트 36개, Target 단위 테스트 4개: 총 40개 통과, 실패·오류·건너뜀 0개.
- 문서 내부 로컬 링크와 `git diff --check` 확인.
- 업로드 대상 텍스트의 대표적인 자격 증명 패턴 확인: 발견 없음. 완전한 비밀정보·권리 감사 또는 과거 이력 정리를 의미하지 않음.
- Gradle 구식 API 및 Scanner Kotlin `jvmTarget` 설정 관련 경고가 남음. 현재 빌드 성공과 별개로 도구 업그레이드 시 정리 필요.
- 실기기 계측 검증은 이번 작업 범위에 포함하지 않음.
