# 검증 상태와 알려진 한계

## 증거 수준

현재 상태는 소스 검토와 저장소 기록에 근거한 연구 프로토타입입니다. 아래의 과거 결과는 현재 커밋에 대한 재실행 결과와 구분합니다.

| 구분 | 상태 |
| --- | --- |
| 단위 테스트 | `app/src/test`에 정합, 화면 검출, gain, 플랫필드 근사, 다중 카메라 관련 테스트 존재 |
| 과거 README 기록 | 당시 단위 테스트 13개, 에뮬레이터 통합 18/18, Galaxy Tab S2 ↔ Galaxy S25 루프 동작 확인을 기록 |
| 과거 기록의 한계 | 해당 주장 전체를 재현하는 버전 고정 데이터·실기기 원본·자동 통합 실행 환경이 함께 제공되지 않음 |
| 현재 실기기 정확도 | 독립 계측과 반복성 검증 미완료; 잔여 RMS 1.5% 달성·번인 비가시성 보증 불가 |

이 문서 작성 시점의 빌드·단위 테스트 결과는 [변경 기록](changelog.md)에 별도로 남깁니다. 빌드 성공은 측정 정확도의 증거가 아닙니다.

## 알려진 한계

1. **패널 결함과 비네팅 혼동.** 대상 화면에서 추정한 방사형 플랫필드가 실제 패널의 중심부·가장자리 열화를 제거할 수 있습니다. 처리 전·후 지표를 함께 보존하고 독립 캘리브레이션으로 검증해야 합니다.
2. **출력 모델.** 선형 휘도로 간주한 gain을 RGB 코드값·알파에 적용합니다. 실제 휘도 응답과 보고서의 예상 밝기 손실은 다를 수 있습니다. 기본 Target 5% 설정의 8비트 알파는 약 14단계, Scanner 10% 설정은 약 27단계에 불과합니다.
3. **카메라 처리.** YUV/JPEG 역감마 2.2는 근사입니다. RAW 지원 진단이 실제 RAW 촬영·교정 구현을 의미하지 않습니다. 주사율에 맞춘 노출이 모든 PWM·밴딩을 없애지는 않습니다.
4. **정합.** dot-grid는 다점 호모그래피를 맞추며 비선형 렌즈 왜곡은 잔차로 남깁니다. 반복·최종 측정에서 모서리 기반 정합으로 전환될 수 있어 기준 좌표의 일관성을 검증해야 합니다.
5. **해상도.** 네이티브 크기 그리드·PNG는 보간 결과를 포함합니다. 카메라 광학계와 샘플링 한계 이하의 결함을 실제로 분해한다는 뜻은 아닙니다.
6. **후보 선택·복구.** 무보정 후보 선택과 실패 시 보정 OFF 경로를 보강했습니다. 통신 단절 후 원격 상태 확인, 세션 시작 전 프로파일 전체 복원, 최종 적용 맵과 보고서의 일치는 추가 검증이 필요합니다. [테스트 보강 범위](testing.md)를 참고하세요.
7. **경로 차이.** 앱 내부 RGB/화이트밸런스 실험과 시스템 알파 오버레이의 보정 능력이 다릅니다. 현재 합격은 gray70·gray25의 RMS/P95 기준이며 RGB 전체 품질 통과를 의미하지 않습니다.
8. **AI 신뢰도.** 현재 비전 모델 판단이 교차 검증 신뢰도 하한을 올릴 수 있습니다. 모델의 confidence는 교정된 계측 신뢰구간이 아닙니다.
9. **합성 시험.** 일부 파이프라인 테스트는 휘도에 gain을 직접 곱하는 이상적 모델을 사용합니다. 디스플레이 감마·양자화·카메라 처리·오버레이 합성을 모두 검증하지는 않습니다.

## 다음 실험 설계

- 무보정 상태를 동일 조건에서 반복 촬영해 픽셀/영역별 변동과 전체 밝기 드리프트를 분리합니다.
- 균일 기준 광원 또는 여러 위치·거리의 촬영으로 카메라 음영과 패널 결함을 구분합니다. 180° 회전만으로는 방사형 성분 분리가 충분하지 않을 수 있습니다.
- 알려진 강도·위치의 인공 결함과 정상 영역을 함께 평가하여 검출 실패 및 오보정을 측정합니다.
- 보정에 사용하지 않은 계조, 패턴 면적, 화면 밝기에서 평가합니다.
- 실제 오버레이 상태를 재촬영하고 무보정 기준과 비교합니다.
- 후보 최적화용 촬영과 최종 평가용 촬영을 분리하고 재거치 후에도 검증합니다.

최소 기록 항목: 커밋 ID, 기기/OS/카메라 ID, 노출·ISO, 화면 밝기·색상 모드·주사율, 지그 배치, 프레임 수, 전처리 설정, 보정맵 ID, 처리 전후 RMS/P95, 반복 편차, 실제 밝기 손실, 적용 경로, 실패·누락 여부.

## 자료 해석

성공 사례만 선택하지 않고 실패·무효 세션을 함께 보고합니다. 연구 목적으로 생성한 측정 지표는 수리 완료 인증이나 중고 제품의 품질 보증에 사용하지 않습니다. 합성 데이터와 실기기 데이터, 실측값과 모델 추정값은 구분하여 표시합니다.
