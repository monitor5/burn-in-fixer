# 개선 로드맵

기능 수보다 측정의 재현성과 독립적인 효과 검증을 우선합니다. 아래 항목은 예정 작업이며 이번 문서 정리에서 구현한 기능이 아닙니다.

| 우선순위 | 작업 | 완료 조건 |
| --- | --- | --- |
| P0 | 무보정·이전 검증 프로파일을 최적 후보에 포함 | 보정이 악화되면 기존 상태 유지 |
| P0 | 임시 맵/확정 맵 분리와 오류·취소·드리프트 복구 | 실패 경로 테스트에서 실제 적용 상태와 보고서 일치 |
| P0 | 반복 촬영·원본 메타데이터 기반 검증 도구 | 반복 편차와 검출 가능한 최소 결함을 재현 가능하게 산출 |
| P1 | 독립 플랫필드와 패널 음영 분리 | 방사형 패널 결함을 보존하는 대조 실험 통과 |
| P1 | 카메라 응답 및 출력 경로별 LUT | 코드값·알파와 실측 휘도 대응 확인 |
| P1 | 비선형 렌즈 왜곡 및 정합 일관성 | 전후 동일 좌표계에서 잔차·오차 한계 검증 |
| P1 | 독립 최종 평가 | 미사용 계조·재거치·오버레이에서 개선 재현 |
| P2 | 밝기·계조·RGB별 프로파일, 콘텐츠 렌더러 | 단일 gain 혼합 대비 성능 개선과 색 편차 제한 입증 |
| P2 | AI를 설명·재촬영 보조로 제한하는 실험 | 계측 신뢰도 상승에 AI 단독 판정을 쓰지 않는 대조 평가 |
| P2 | 측정 세션 상태와 UI 분리, 재현 가능한 빌드 | Activity 밖에서 세션·복구 테스트, Wrapper/CI 도입 |
| P2 | 인증 페어링·전송 제한 | 잘못된 상대의 제어·맵 전송 거부 |

고해상도 맵은 광학 분해능·출력 양자화를 확인한 뒤 개선합니다. 일반 앱용 오버레이와 전용 뷰어용 RGB 보정은 별도의 평가 목표를 둡니다.
