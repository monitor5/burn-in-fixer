# OLED Uniformity Research — burn-in-fixer

외부 Android 카메라로 OLED 화면의 위치별 밝기 편차를 측정하고, 출력 감쇠를 통해 시각적 균일도 개선 가능성을 연구하는 실험용 프로젝트입니다.

**비상업적 연구·교육 전용 · 실험 단계 · 제조사 비공식 프로젝트**

OLED 픽셀의 물리적 열화를 복구하지 않습니다. 상대적으로 밝은 영역의 출력을 낮추는 방법을 실험하며, 측정 정확도·개선 효과·특정 기기 호환성을 보증하지 않습니다.

Samsung Electronics, Samsung Display 및 그 계열사와 제휴·후원·승인 관계가 없습니다. Samsung, Galaxy 등 제품명은 기기 식별과 실험 환경 설명에만 사용하며 해당 권리자의 상표입니다. 제조사 공식 진단·수리·캘리브레이션 도구가 아닙니다.

## 프로젝트 구성

| 구성 | 설치 대상 | 역할 |
| --- | --- | --- |
| `burn-in-fixed` / Target | 측정 대상 또는 비교용 Android 기기 | 패턴 출력, 보정맵 수신, 앱 내부 보정, 시스템 알파 오버레이 |
| `burn-in-camera` / Scanner | 카메라를 사용하는 별도 Android 기기 | 촬영, 정합, 분석, 반복 보정, 결과 저장 |
| 선택적 Reference | Target 앱을 설치한 세 번째 기기 | 보정을 끈 비교 화면을 제공하는 화이트밸런스 실험 |

기본 번인 측정에는 두 기기를 사용합니다. 비교 기기를 이용한 화이트밸런스 실험에는 세 기기가 필요합니다.

## 현재 구현과 한계

- Camera2 노출 제어, 다중 프레임 절사 평균, YUV/JPEG 분석.
- 비대칭 마커 방향 판별, dot-grid 다점 호모그래피, 네이티브 크기 보정맵.
- gray70·gray25·RGB 패턴 측정과 반복 보정.
- 지원 기기의 동시 다중 카메라 교차 검증, Gemini Nano 기반 실험적 시각 신뢰도 판단.
- 앱 내부 RGB 감쇠와 별도 화이트밸런스 레이어, 일반 앱용 검정 알파 오버레이.
- JSON 리포트와 분석 이미지 저장.

네이티브 크기의 맵이 네이티브 픽셀 수준의 측정 정확도를 뜻하지는 않습니다. 방사형 플랫필드는 대상 화면에서 추정한 근사이며, 독립적인 카메라 캘리브레이션이 아닙니다. 앱 내부 RGB 보정 결과를 시스템 오버레이 성능으로 해석해서는 안 됩니다. 자세한 한계와 검증 계획은 [검증 문서](docs/validation.md)를 참고하세요.

## 시작하기

1. [설치·실험 가이드](docs/getting-started.md)에 따라 두 앱을 빌드하고 설치합니다.
2. 같은 신뢰 가능한 Wi-Fi에 연결하고 대상 앱의 역할을 **조정설비**로 선택합니다.
3. 대상 화면과 카메라를 암실 지그에 고정하고 밝기·색상 모드·방향을 유지합니다.
4. Scanner에서 조정설비 IP로 연결하고 **측정 시작**을 누릅니다.
5. 보정 전후를 확인하고 결과와 실험 조건을 함께 기록합니다.

현재 TCP 제어 채널은 인증·암호화를 제공하지 않습니다. 실험용 로컬 네트워크에서 사용하고 인터넷에 포트를 노출하지 마세요. 측정 실패·중단 시 대상 기기에 후보 보정이 남을 수 있으므로 보정을 끄고 상태를 확인하세요.
